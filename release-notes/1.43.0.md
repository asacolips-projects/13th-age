## New Features

### New Character Sheet (Optional)

A brand-new character sheet for PCs. This is not enabled by default, in order to use it, select the "Sheet" item in a character sheet title bar, open the "This Sheet" dropdown, and select "Character Sheet V3".

Highlights in this new sheet:

- Efficient layout with less scrolling.
- Support for Foundry-native font-size and theme controls (Game settings -> Core -> User Interface).
- Seldom-changed things are display only most of the time, toggle to "edit mode" to change your class or level or backgrounds.
- Customizable tabs, so you can organize powers and items in the most useful way for you. Add a tab for "spells by level" or "interrupts by custom group".
- "Loadout" tab for tracking magic item and feat slots.
- Resting and incrementals have a new UI.
- Better new-PC experience, with guidance for where to start.
- Lots of usage patterns and functions that are carried forward from the current sheet.

### PC Vulnerability and Resistance

Only available with the new V3 sheet, PCs now have fields for recording their vulnerabilities and resistances. This doesn't (yet) interact with active effects or attack rolls, but you can write them down.

## Behavior Changes

- Character classes are detected the same way for every actor, whether or not "Automate Base Stats From Class" is enabled: the stored `detectedClasses` value is now deduplicated and sorted in both cases. Previously actors with the automation setting off kept whatever order and duplicates their history had left behind.
