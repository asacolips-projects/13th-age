## Features

- Adds a new LootV2 sheet similar to the action and power sheets.
- Adds custom group field to equipment and loot.
- Loot and equipment can now be organized into custom groups alongside powers.
- Improved display of attack changes (shield, off hand weapon, etc.) on the v3 sheet.

## Bug Fixes
- Updated the v3 character sheet to highlight when a key modifier is active.
- Refactored how fields are saved on the v3 sheet to improve key modifier handling. This should resolve the bug where ability modifiers would seemingly randomly reduce to very lower numbers.
